Django — высокоуровневый Python-фреймворк для разработки веб-приложений.

Django использует архитектуру MVT: Model, View, Template.

Model отвечает за работу с данными.
View обрабатывает запросы и формирует ответы.
Template отвечает за отображение HTML.

Django ORM позволяет взаимодействовать с базой данных через Python-код.

Django также предоставляет систему аутентификации пользователей и административную панель.
