## Задание 2. Изучение платформы PromptHub

PromptHub — платформа для создания, хранения, тестирования и управления промптами. Я изучила примеры промптов и выбрала три, которые считаю наиболее полезными для повседневных задач.

### 1. Fact Check List — проверка фактов

**Назначение:** помогает выявлять утверждения в ответах AI, которые необходимо дополнительно проверить.

**Как работает:** после основного ответа модель формирует список фактов, от достоверности которых зависит правильность предоставленной информации.

**Практическое применение:** полезен при изучении новых тем, подготовке учебных заданий, анализе статей и работе с информацией из интернета.

**Почему мне понравился:** помогает критически оценивать ответы AI и обращать внимание на потенциально недостоверную информацию.

### 2. Document a Repository — документирование проекта

**Назначение:** помогает создавать техническую документацию для программных проектов.

**Как работает:** сначала AI запрашивает название репозитория и тип необходимой документации, например README, API documentation, code comments или contribution guidelines. Затем задаёт 1–2 уточняющих вопроса для подготовки более качественного результата.

**Практическое применение:** полезен для создания README.md, описания API, документирования архитектуры приложения и подготовки проекта к публикации на GitHub.

**Почему мне понравился:** позволяет экономить время на документировании кода и помогает поддерживать документацию проекта в понятном и структурированном виде.

### 3. Code Review — анализ и улучшение кода

**Назначение:** помогает проверять качество программного кода и находить потенциальные проблемы.

**Как работает:** AI анализирует структуру проекта, предлагает создать файл app-tree.md с описанием структуры папок и файлов, проверяет код на ошибки, опечатки и дублирование, а также рекомендует улучшения производительности и читаемости.

**Практическое применение:** полезен при ежедневной разработке, рефакторинге, подготовке Pull Request и проверке собственного кода перед отправкой в репозиторий.

**Почему мне понравился:** помогает обнаруживать проблемы на ранних этапах разработки и улучшать качество кода.

### Вывод

Все три промпта могут использоваться в повседневной работе разработчика. Fact Check List помогает проверять достоверность информации, Document a Repository упрощает создание документации, а Code Review способствует повышению качества программного кода.

Использование готовых промптов позволяет экономить время, структурировать рабочие процессы и эффективнее взаимодействовать с языковыми моделями.
